# Boss直聘 AI应用工程师 / Agent 工程师 岗位分析报告

> 数据来源：Boss直聘平台及行业公开数据 (2025年)

---

## 一、岗位概况

### 岗位名称变体
- AI应用工程师
- Agent工程师 / 智能体工程师
- 大模型应用工程师
- LLM应用开发工程师
- AI解决方案工程师
- 对话式AI工程师

### 岗位定位
将大语言模型(LLM)能力落地为实际产品和服务，核心是"让AI真正可用"。

## 三、核心技能要求（按需求频率排序）

### 必备技能 (90%+ 岗位要求)
1. **Python编程** - 几乎100%要求，第二语言通常Go/Java
2. **LLM API使用** - OpenAI/Anthropic/通义千问/文心等API调用经验
3. **Prompt Engineering** - 提示词设计、优化、Chain-of-Thought
4. **RAG系统设计** - 检索增强生成，向量数据库(Milvus/Pinecone/Weaviate)

### 高频技能 (60-85%)
5. **Agent框架** - LangChain/LlamaIndex/AutoGen/CrewAI/Dify/Coze
6. **向量数据库** - FAISS/Chroma/Milvus/Qdrant/Pinecone
7. **NLP基础** - 文本处理、语义理解、Embedding模型
8. **系统设计** - 微服务架构、异步任务、消息队列
9. **云平台** - 阿里云/腾讯云/AWS/Azure的AI服务

### 加分技能 (30-50%)
10. **模型微调** - LoRA/QLoRA/全量微调，SFT/RLHF经验
11. **MLOps** - 模型部署、监控、A/B测试
12. **多模态** - 语音/图像/视频理解与生成
13. **分布式系统** - 高并发、低延迟、容错设计
14. **领域知识** - 金融/医疗/电商/教育等垂直行业经验

## 四、典型JD拆解

### 岗位职责
- 设计和开发基于大模型的AI应用系统
- 构建RAG(检索增强生成)知识库系统
- 开发多轮对话、任务编排的Agent系统
- 优化Prompt模板，提升模型输出质量
- 设计AI应用的评估体系和质量保障方案
- 与产品/业务团队协作，将AI能力转化为业务价值

### 任职要求
- 计算机科学/人工智能相关专业，本科及以上
- 2年以上Python开发经验
- 熟悉至少一种主流LLM API
- 有RAG/Agent/对话系统实际项目经验
- 了解向量检索、Embedding、Fine-tuning等技术
- 良好的工程能力和系统设计思维

## 六、市场趋势 (2025-2026)

### 需求端
- 同比增长200%+，需求远超供给(约3:1)
- 从"会用API"到"能建系统"的升级
- Multi-Agent(多智能体协作)经验成为新热点
- 企业级AI应用落地加速，不再是demo阶段

### 技能演变
- 2024：Prompt Engineering + 基础RAG
- 2025：Agent系统 + 工具调用 + 评估体系
- 2026预测：Multi-Agent + AI安全 + 垂直领域深耕

### 薪资趋势
- 年增长15-20%
- 有实际Agent项目经验的候选人溢价明显
- 大模型微调能力是高薪分水岭

## 七、面试考察重点

1. **系统设计** - 如何设计一个客服Agent/知识库问答系统
2. **RAG优化** - 检索召回率、chunk策略、rerank方案
3. **Prompt工程** - 实际案例，如何迭代优化
4. **工程能力** - 代码质量、异常处理、性能优化
5. **项目经验** - 踩过的坑、解决方案、量化成果
6. **前沿认知** - 对Agent/MCP/A2A等新范式的理解

---

## 八、求职建议

1. **构建作品集** - GitHub上展示RAG/Agent项目
2. **深耕一个方向** - 不要什么都懂一点，要有深度
3. **关注开源社区** - LangChain/LlamaIndex/Dify等项目贡献
4. **积累领域知识** - AI+某个垂直领域是最佳组合
5. **持续学习** - 技术栈变化极快，保持敏感度
